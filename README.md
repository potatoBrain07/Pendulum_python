
# Pendulum

This is a pendulum simulation built in Python. 

----------

## About

This project uses the **RK4 numerical integrator** to compute angular position and velocity of a real life pendulum\(shown right\). There is another pendulum\(shown left\) which uses small angle approximation.

The aim of this project is to show the difference between a small angle pendulum which we assume in many physics problems, and a real-life pendulum. However, in both pendulums, we assume the string is inextensible and massless.

----------

## Installation

 - Clone the repository:
   ```bash
   git clone https://github.com/potatoBrain07/Pendulum_python.git
   ```
 - Install dependencies:
   ```bash
   pip3 install -r requirements.txt
   ```
 - Run the program:
   ```bash
   python3 main.py
   ```
